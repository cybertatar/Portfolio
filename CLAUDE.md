# Portfolio — правила работы

Сайт-портфолио Даниила Тынчерова на Astro (статическая сборка).

- Продакшн: https://cybertatar.github.io/Portfolio/ — деплоится сам при каждом пуше в `main` (`.github/workflows/deploy.yml`).
- Превью для согласования: артефакт https://claude.ai/artifact/CXQuMo6vfckqykF1kN2wei (видит только владелец).

## Как работаем

1. Изменения делаем в отдельной ветке, `main` не трогаем.
2. Перед пушем: `npm run build` (включает `astro check`) и `npm run format:check` без ошибок.
3. Показываем результат в превью: обновляем артефакт по тому же URL сборкой ветки. Из `dist/` убрать обёртку документа (`<html>/<head>/<body>`), пути сделать относительными, папку `_astro` переименовать (артефакт не принимает имена с `_`). Скрипты не терять: Astro кладёт после `</html>` встроенный скрипт и `<script src>` на файл главной в `_astro/` с подчёркиваниями в имени; оба перенести в превью вместе с содержимым `<body>`, файл переименовать (например, `astro/home.js`).
4. Сливаем в `main` только после явного «ок» владельца.
5. В конце сессии обновляем раздел «Статус» ниже.

## Устройство

- Контент (тексты RU/EN, ссылки, кейсы, пути к картинкам): `src/content/site.ts`.
- Токены дизайн-системы: `src/styles/tokens`. Примитивы: `src/components/ui`.
- Главная: `src/pages/index.astro`, поведение (ужатие профиля, стопка карточек): `src/scripts/home.ts`.
- Пути к файлам из `public/` — через `withBase()` из `src/scripts/url.ts` (сайт живёт в подпапке `/Portfolio/`).
- Safari: не сочетать процентный `flex-basis` с `min-width`/`max-width` (Safari делит строку по сырому проценту, и соседняя колонка вылезает за край). Задавать одним `clamp()`, как у сайдбара. Проверяю только в Chromium, поэтому правки вёрстки владелец смотрит в Safari.

## Статус

- Готово: главная страница (перенесена из черновика Claude Design), портрет, деплой на GitHub Pages. Контент главной ограничен шириной 1600px (`--layout-content-max`) и центрирован на широких экранах.
- Ждёт материалов: обложка кейса WB (16:9) — сейчас плейсхолдер; ссылки на кейсы и CV ведут на `#`.
- Готово: обложка кейса PSB (`public/assets/cases/psb-cover.webp`, 1920×1080). Собирается из `tools/case-covers/psb.html` скриншотом 1920×1080 → WebP; экраны выгружены из Figma-файла PSB (секция «mockup for claude») в `tools/case-covers/psb/`, корпус iPhone 17 Pro (скрытый слой `bezel` оттуда же) — общий `tools/case-covers/iphone-17-pro.png`. Веер из пяти телефонов на пергаменте, фон — едва заметный узор из пиксельных монеток и сердечек. Владелец отказался от: плоских телефонов с пиксельными углами (нужен реальный iPhone 16 Pro/17), всплывающих цифр лута, монет поверх экранов, плашки-подсказки предмета, курсора-перчатки на обложке.
- На согласовании (ветка `claude/fervent-feynman-9vku5j`): обложка кейса BittVPN (`public/assets/cases/bittvpn-cover.webp`, 1920×1080), собирается из `tools/case-covers/bittvpn.html` так же. Посадочный талон «ВЫ ✈ DE» (откуда угодно → Германия, Франкфурт) рядом с iPhone 17 Pro с главным экраном: тёмная полоса с точечным логотипом, поля из моковых данных приложения (iPhone_DE, 10 мс, до 30.09, 3/5), на корешке QR со ссылкой на портфолио и плашка «Онлайн». Фон — пергамент, как у PSB, с едва заметным узором из точечных глобусов и самолётиков. Крупные коды — точками из своих глифов 5×7 (`bittvpn/glyphs.js`; шрифт приложения Nothing Font не распространяем), мелкий текст — Martian Mono. Экран — Figma-файл BittVPN, секция «for claude», фрейм `t-main`; выгрузка через `download_assets` в 3x (`use_figma` клонировать экраны не может — нет шрифтов). Цвета приложения: фон #0A0C0F, зелёный #72D769. Владелец отказался от: повтора приёма PSB (веер телефонов), тёмного фона на всю обложку, LED-табло вылетов (и на всю ширину с часами и шестью строками — перегруз, и маленькой плашкой — несуразно). Отклонённые наброски: стикеры с кодами стран вокруг телефона, точечные маршруты от телефона к странам.
- Готово (ветка `claude/nifty-knuth-pmqi27`, слита в `main`): главная в стиле сдержанной MMORPG. Ступенчатые пиксельные углы без обводок (`src/styles/pixel.css`), пиксельные иконки (`src/content/pixel-icons.ts`), шрифт Handjet для подписей, плашка «25 lvl», строка «Класс», статус «Открыт к предложениям» (`profile.status`, `undefined` скрывает). Прикольчики: уровень считается от `profile.birthday` и в день рождения показывает «Level up!», курсор-меч и перчатка (`src/assets/cursors`), у закрытого кейса по клику «Не хватает маны» (диалог `src/scripts/dialog.ts`). Владелец любит эстетику The Legend of Zelda, ArcheAge и Sousou no Frieren (сам отмечает, что они светлые и на тёмную тему не переносятся). Тема только светлая (решение по NN/g: светлая лучше читается, тёмный режим и переключатель не делаем): пергаментный фон, карточки светлее фона, текст цвета чернил, голубой акцент (`--sky-*`), диалог остаётся тёмным. Все уровни текста проходят AA. Отступы: единая рамка 24px на десктопе (края, колонки, между карточками), 16px на мобильном; внутренние поля не больше внешних. Отклонены тёмные палитры: «Золото», «Мана», «Консоль», «Эпик», «Хвойный», тёплая «угольная»; прежняя тёмная (холодный чёрный + коралловый) лежит в истории ветки. Владелец отказался от: обводок, интерпунктов, счётчиков, заголовка над кейсами, номеров квестов, выделения избранного кейса, панели инструментов.
- Готово: картинка превью ссылки (`public/assets/og-cover.png`, 1200×630) в светлой стилистике с портретом. Собирается из `tools/og-cover/og-cover.html` скриншотом 1200×630; после замены поднять `?v=` в `BaseLayout.astro`, иначе мессенджеры покажут старую из кэша; уровня и статуса на ней нет, чтобы не устаревала в кэше мессенджеров.
- Готово (ветка `claude/focused-cerf-hp9u9s`): футер — поляна цветов сверху в честь заклинания Фрирен (`src/scripts/meadow.ts`, цвета `--flora-*`). Когда футер появляется, цветы распускаются волной в четыре кадра (росток, бутон, полураскрыт, цветок); под мышкой изредка вырастают цветок, трава или бутон (не вплотную к другому цветку), на телефоне — кружок по тапу; с небольшим шансом выпрыгивает лягушка. Над футером курсор — посох (`src/assets/cursors/staff.png`). Высоту футера считает `initCardStack`: прокрутка кончается ровно, когда последний кейс у верха, а футер у низа экрана (минимум 160px на десктопе, на 1440×900 и ниже кейс уходит чуть выше). Владелец отказался от: цветов вдоль линии сбоку (нужен вид сверху), появления по клику (нужно по наведению), сплошной дорожки цветов под курсором, растягивания футера под сайдбар (пустота под сайдбаром — норм).
- Готово (ветка `claude/eloquent-turing-m9yqbo`): внизу футера вместо подписи «Даниил Тынчеров — 2026» ряд пиксельных кнопок по центру (`profile.socials`): Telegram, Instagram, Discord, LinkedIn, почта, GitHub, Figma.
