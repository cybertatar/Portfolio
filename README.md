# Portfolio

Личный сайт-портфолио Даниила Тынчерова на [Astro](https://astro.build). Главная: карточка профиля слева и лента кейсов, которые «складываются в стопку» при скролле. Перенесена из черновика Claude Design. Сборка статическая: на выходе обычные HTML/CSS/JS-файлы, которые можно отдавать любым веб-сервером.

## Требования

- Node.js 22+ (версия указана в `.nvmrc`)

## Команды

| Команда           | Что делает                              |
| ----------------- | --------------------------------------- |
| `npm install`     | Установить зависимости                  |
| `npm run dev`     | Dev-сервер на http://localhost:4321     |
| `npm run build`   | Проверка типов и сборка сайта в `dist/` |
| `npm run preview` | Локально посмотреть собранный `dist/`   |
| `npm run format`  | Отформатировать код через Prettier      |

## Структура

```
public/            статические файлы (favicon, картинки) — копируются как есть
src/pages/         страницы; каждый файл = маршрут
src/layouts/       общие шаблоны страниц
src/components/    переиспользуемые компоненты
src/styles/        глобальные стили и переменные
```

## Где что лежит

| Путь                               | Что это                                                                                         |
| ---------------------------------- | ----------------------------------------------------------------------------------------------- |
| `src/content/site.ts`              | Тексты профиля и кейсов (RU/EN), ссылки, пути к картинкам                                       |
| `src/pages/index.astro`            | Главная: раскладка профиля и ленты                                                              |
| `src/scripts/home.ts`              | Авто-ужатие профиля по высоте и анимация стопки карточек                                        |
| `src/components/ui`                | Примитивы дизайн-системы: Button, IconButton, Chip, Eyebrow, GlassTag, Badge, ContactRow, Media |
| `src/components/ProjectCard.astro` | Карточка кейса в ленте                                                                          |
| `src/styles/tokens`                | Токены: цвета, типографика, отступы, радиусы, эффекты                                           |

## Картинки

Пока вместо портрета и обложек стоят плейсхолдеры. Положите файл в `public/images/` и пропишите путь в `src/content/site.ts`:

- портрет (5:4): `profile.portrait`;
- обложка кейса (16:9): поле `cover` у кейса.

## Язык

По умолчанию страница на русском. Английский включается автоматически, если первый язык браузера не русский: тексты берутся из атрибутов `data-en`.

## Хостинг

После `npm run build` скопируйте содержимое `dist/` на сервер и отдавайте его как статику. Пример для nginx:

```nginx
server {
  listen 80;
  server_name example.com;
  root /var/www/portfolio;
  index index.html;

  location / {
    try_files $uri $uri/ $uri.html =404;
  }
}
```

## VS Code

При открытии проекта VS Code предложит поставить рекомендуемые расширения (Astro, Prettier, EditorConfig). Форматирование при сохранении уже включено в `.vscode/settings.json`.
