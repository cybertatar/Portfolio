# Portfolio — правила работы

Сайт-портфолио Даниила Тынчерова на Astro (статическая сборка).

- Продакшн: https://cybertatar.github.io/Portfolio/ — деплоится сам при каждом пуше в `main` (`.github/workflows/deploy.yml`).
- Превью для согласования: артефакт https://claude.ai/artifact/CXQuMo6vfckqykF1kN2wei (видит только владелец).

## Как работаем

1. Изменения делаем в отдельной ветке, `main` не трогаем.
2. Перед пушем: `npm run build` (включает `astro check`) и `npm run format:check` без ошибок.
3. Показываем результат в превью: обновляем артефакт по тому же URL сборкой ветки. Из `dist/` убрать обёртку документа (`<html>/<head>/<body>`), пути сделать относительными, папку `_astro` переименовать (артефакт не принимает имена с `_`). Скрипты не терять: Astro кладёт после `</html>` встроенный скрипт и `<script src>` на файл главной в `_astro/` с подчёркиваниями в имени; оба перенести в превью вместе с содержимым `<body>`, файл переименовать (например, `astro/home.js`). Страницы кейсов кладутся рядом отдельными файлами со своим документом (`psb.html`), ссылки между ними — `psb.html` и `index.html`. Пути есть и внутри JSON в data-атрибутах (`&quot;/assets/…`, логотипы банков в сцене) — их тоже сделать относительными, иначе картинки в превью не грузятся. Общий CSS (`Media.*.css`, в нём токены) меняет имя при любой правке токенов: после сборки сверить все `astro/…` из обеих страниц со списком файлов артефакта и догрузить новые, иначе вёрстка превью разваливается.
4. Сливаем в `main` только после явного «ок» владельца.
5. В конце сессии обновляем раздел «Статус» ниже.

## Устройство

- Контент (тексты RU/EN, ссылки, кейсы, пути к картинкам): `src/content/site.ts`.
- Токены дизайн-системы: `src/styles/tokens`. Примитивы: `src/components/ui`.
- Главная: `src/pages/index.astro`, поведение (ужатие профиля, стопка карточек): `src/scripts/home.ts`.
- Пути к файлам из `public/` — через `withBase()` из `src/scripts/url.ts` (сайт живёт в подпапке `/Portfolio/`).
- Висячие предлоги убирает типограф `src/typograph.ts` — его вызывает `src/middleware.ts` для каждой страницы при сборке: неразрывный пробел после предлогов, союзов, артиклей (русских слов из одной-двух букв и списков `RU`/`EN`), между числом и словом, перед тире и частицами; обрабатываются текст и `data-*` атрибуты. Пробел, стоящий один между двумя тегами, типограф не трогает (его не отличить от пробела между flex-элементами) — там `&nbsp;` вручную (как в «Шаг N из M» у `Race`). Склеивать все короткие слова нельзя: английские цепочки («how to do it and how to see») не влезали в телефон.
- Язык: русский в HTML, английский — для браузеров не на русском (решается в `<head>` до отрисовки, `?lang=en` / `?lang=ru` в адресе переопределяют). `data-en` — текст, `data-en-label` / `-alt` / `-title` / `-src` / `-poster` — атрибуты, любой другой `data-en-x` заменяет `data-x`, который читает скрипт (подписи забега, печатаемые реплики, банки в сцене). Текст с разметкой внутри — два блока `data-lang="ru"` / `data-lang="en"`, лишний скрывает CSS. Двуязычные строки — `Localized` / `Text` и помощники `ru()` / `en()` из `site.ts`.
- Safari: не сочетать процентный `flex-basis` с `min-width`/`max-width` (Safari делит строку по сырому проценту, и соседняя колонка вылезает за край). Задавать одним `clamp()`, как у сайдбара. Проверяю только в Chromium, поэтому правки вёрстки владелец смотрит в Safari.
